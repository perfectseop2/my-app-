# my-app-

\# 🔬 Semiconductor Process Engineer Portfolio



반도체 공정기술 엔지니어 직무를 지망하는 김도윤의 개인 포트폴리오 웹사이트입니다.

8대 공정에 대한 이해, 공정 개선 프로젝트, 데이터 분석 역량을 하나의 페이지로 정리했습니다.



\*\*🔗 Live Demo:\*\* \[https://yourid.github.io/portfolio](https://yourid.github.io/portfolio) <!-- GitHub Pages 배포 후 실제 주소로 교체 -->



\---



\## 📌 소개



수 나노미터의 미세한 편차가 소자 수율 전체를 좌우한다는 점에 매료되어 반도체 공정기술 엔지니어를 목표로 하고 있습니다. 이 포트폴리오는 실습 기반의 공정 이해도, DOE·SPC를 활용한 데이터 기반 문제해결 프로젝트, 관련 자격 및 교육 이력을 담고 있습니다.



\## ✨ 주요 특징



\- \*\*웨이퍼 모티프 디자인\*\* — 노치가 있는 실리콘 웨이퍼와 다이 그리드를 SVG로 직접 구현한 히어로 비주얼

\- \*\*리소그래피 앰버 컬러\*\* — 감광액 보호용 옐로 라이트에서 착안한 앰버(#FFB627) 포인트 컬러

\- \*\*공정 순서 기반 구성\*\* — 산화 → 포토 → 식각 → 박막증착 → 이온주입 → 금속배선 → EDS → 패키징, 실제 8대 공정 흐름을 그대로 반영한 타임라인

\- \*\*LOT 트래블러 스타일 프로젝트 카드\*\* — 배경 · 진행 · 결과(수치)를 공정 실습 전표 형식으로 정리

\- \*\*반응형 \& 접근성\*\* — 모바일 대응, 키보드 포커스 표시, `prefers-reduced-motion` 지원

\- \*\*의존성 없는 순수 코드\*\* — 빌드 도구 없이 `index.html` 파일 하나로 동작




\## 🌐 GitHub Pages로 배포하기



1\. 이 저장소를 GitHub에 push합니다.

2\. \*\*Settings → Pages\*\* 이동

3\. \*\*Source\*\*를 `Deploy from a branch`로 설정, 브랜치는 `main` / 폴더는 `/ (root)` 선택

4\. 몇 분 후 `https://yourid.github.io/portfolio` 에서 확인 가능



\## ✏️ 커스터마이징 가이드



실제 지원용으로 사용하려면 `index.html`에서 아래 항목을 본인 정보로 교체하세요.



\- \[ ] 이름 / 직무 타이틀 (`<h1>`, `.role`)

\- \[ ] 자기소개 문구 (`#about` 섹션)

\- \[ ] 프로젝트 3건의 배경·진행·결과 및 수치 (`#projects` 섹션의 `.proj-card`)

\- \[ ] 8대 공정 실습 경험 및 숙련도 바 (`#process` 섹션의 `.bar` width 값)

\- \[ ] 학력 · 자격증 정보 (`#education` 섹션)

\- \[ ] 이메일 / 전화번호 / GitHub / LinkedIn (`#contact` 섹션의 `.contact-list`)
